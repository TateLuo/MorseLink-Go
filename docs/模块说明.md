# 模块说明（V1.8）

## 主流程
- 入口：`src/main.cpp`
- 运行方式：状态机驱动
  - `BOOT`
  - `CONFIG`
  - `ONLINE`
  - `DEGRADED`
  - `CRITICAL_POWER`
  - `ERROR`

主循环每轮执行：
1. 显示刷新、输入处理、蜂鸣器/LED 更新
2. Net/MQTT 状态机推进
3. 电池采样与分级策略
4. 运行状态计算与切换
5. UI 时钟刷新

## 公共类型

### `lib/Common/src/AppState.h`
- 定义运行状态枚举 `AppState`。

### `lib/Common/src/DeviceConfig.h`
- 定义统一配置模型 `DeviceConfig`：
  - Wi-Fi：`wifiSsid/wifiPwd`
  - MQTT：`mqttHost/mqttPort/mqttClientId/mqttUser/mqttPass`
  - 设备参数：`ledBrightness/tzOffsetSec/battWarnPct/battLimitPct/battCritPct/txEnabled`

## 配置与持久化

### `lib/ConfigManager/src/ConfigManager.*`
- 基于 `Preferences` 的配置读写。
- 新接口：
  - `loadDeviceConfig(DeviceConfig&)`
  - `saveDeviceConfig(const DeviceConfig&)`
  - `resetFactory(DeviceConfig*)`
- 兼容接口：
  - `getWifiConfig/saveWifiConfig`

## 网络

### `lib/NetManager/src/NetManager.*`
- 状态：`IDLE/CONNECTING/CONNECTED/AP_MODE`
- 支持 `begin(const DeviceConfig&)` 参数化启动。
- 支持状态回调 `setStateCallback(...)`。
- AP 配网页支持文本参数：
  - Wi-Fi SSID/PWD
  - MQTT host/port/clientId/user/pass
- NTP 同步采用非阻塞轮询，时区来自配置 `tzOffsetSec`。

## MQTT

### `lib/MqttManager/src/MqttManager.*`
- 状态：`IDLE/TRY_CONNECT/BACKOFF/CONNECTED`
- 支持 `begin(const DeviceConfig&)` 参数化启动。
- 默认鉴权路径：用户名/密码（轻量）。
- 保留 JWT 接口兼容（默认关闭）。
- 功能：
  - 指数退避重连
  - 订阅恢复
  - 离线文本消息队列（RAM 32 条，满时丢最旧）
  - 状态回调 `setStateCallback(...)`

## UI 与交互

### `lib/UIController/src/UIController.*`
- 新增：
  - `bindConfig(DeviceConfig*)`
  - `onConfigChanged()`
  - `setRuntimeState(AppState)`
- 菜单支持设备端配置：
  - `TX Enable`
  - `LED Brightness`
  - `TZ Offset`
  - `Batt Warn/Limit/Crit`
  - `Save Config`
  - `Enter AP Config`
  - `System Log`
- `System Log` 为只读列表。

### `lib/UI/src/ui_menu.*`
- 从固定菜单升级为动态菜单：
  - 可设置标题
  - 可设置条目数与条目文本
  - 保留滚动与高亮

### `lib/UI/src/ui_main.*`
- 主界面瀑布流已落地为事件驱动渲染：11 通道 + 收发脉冲 + 中心发射载波。
- 视觉内核对齐 PC：AGC/包络、IF 扩散核、对数映射、IC-7300 风格配色。
- 空闲时静态待机（无持续刷屏），有收发事件时自动唤醒 16ms 渲染定时器。

## 电池与电源策略

### `lib/BatteryMonitor/src/BatteryMonitor.*`
- 已接入主流程，周期采样并平滑。
- 默认阈值策略：
  - Warn: `<=25%`
  - Limit: `<=15%`
  - Critical: `<=8%`
- 行为：
  - 分级降亮度
  - Limit 阶段禁用 TX
  - Critical 阶段进入 `CRITICAL_POWER` 并执行安全掉电

## 日志

### `lib/LogManager/src/LogManager.*`
- 新增 RAM 环形日志模块。
- 接口：
  - `begin(cap)`
  - `push(tag,msg)`
  - `dump(out,maxLen)`
  - `count()`
  - `get(index,line,maxLen)`
- 主要记录：
  - 状态切换
  - Net/MQTT 状态变化
  - 电池级别变化
  - 配置保存动作

## 输入与按键修复

### `lib/InputManager/src/InputManager.*`
