# MorseLink-Go

MorseLink Go 是一款基于 ESP32-S3 的便携式摩尔斯电码学习与 CW 练习终端，面向业余无线电爱好者、CW 初学者和电子制作爱好者。

它支持连接传统电键，通过真实敲击的方式练习摩尔斯电码，并通过蜂鸣器提供 CW 侧音反馈，通过 LCD 屏幕显示设备状态和输入信息。设备支持 Type-C 和电池供电，适合桌面练习、便携训练和模拟通联演示。

---

## 项目介绍

MorseLink Go 是 MorseLink 系列中的嵌入式端项目，主要用于摩尔斯电码学习、CW 节奏训练和模拟通联练习。

与单纯的软件练习不同，MorseLink Go 更接近真实 CW 操作体验。用户可以连接直键、自动键、单桨或双桨电键，通过实际敲击来熟悉点、划、字符间隔和通联节奏。

本项目硬件已在立创开源平台发布，代码在 GitHub 开源，方便大家学习、复刻和二次开发。

## 主要功能

- 支持传统摩尔斯电键输入
- 支持直键、自动键、单桨、双桨等电键
- 支持蜂鸣器 CW 侧音反馈
- 配备 2 寸 LCD 显示屏
- 支持按键和旋钮交互
- 支持 LED 状态指示
- 支持 Type-C 供电
- 支持电池供电
- 支持 USB / 串口连接电脑
- 基于 ESP32-S3，支持 WiFi 扩展
- 适合摩尔斯电码学习、CW 训练和模拟通联
